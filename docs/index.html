Browse with a flick of the mouse

QuickGestures turns the things you do all day in Chrome into short mouse gestures. Go back, close and reopen tabs, open links in the background and search selected text, without reaching for the toolbar or the keyboard.

Add to Chrome View on GitHub

Free and open source. No tracking, no data collection.

How it works

Hold a mouse button, draw a short line or two, let go. A trail follows the cursor, so you always see the gesture you are drawing.

Right mouse button

On any page

Navigate and manage tabs from anywhere on the page.

  • ← Go back
  • → Go forward
  • ↑ Scroll to top
  • ↓ Scroll to bottom
  • ←→ New tab
  • ↓→ Close tab
  • ↓↑ Reopen closed tab
  • →← Close tabs to the right
  • ↑← Switch to the tab on the left
  • ↑→ Switch to the tab on the right
Left mouse button

On a link

Drag a link to decide where it opens, without losing your place.

  • → Open in a background tab
  • ← Open in a foreground tab
  • ↑ Open in a new window
Left mouse button

On selected text

Select a word or sentence and drag it to look it up.

  • → Search in a new tab
  • ← Search in the current tab

Made to fit the way you browse

The defaults work out of the box. Everything else is yours to change.

  • Your own gesturesAssign any gesture to any action, including reload, duplicate tab, copy link and copy text.
  • Your search engineGoogle, Bing, DuckDuckGo or any site that takes a search URL.
  • Tab order controlChoose where new tabs open and which tab you land on after closing one.
  • A trail you can seePick the color and width, add high contrast, and show the action name while you draw.
  • Site exclusionsTurn gestures off on sites that use the mouse themselves, with simple wildcard patterns.
  • Modifier keysRequire Alt, Ctrl or Shift for link and selection gestures if you drag links a lot.
  • Clickable maps on GoogleClick the map preview in Google results to open Google Maps.
  • Settings that travelSettings sync with your Chrome profile, and you can export and import them.

Private by design

QuickGestures runs entirely in your browser. It has no servers, no analytics and no tracking, and it never sends anything anywhere. Read the privacy policy.

Questions

How do I open the right-click menu on macOS or Linux?

There the menu opens as soon as the button is pressed, so QuickGestures holds it back while you draw. Right-click twice in quick succession to open the menu.

Does it work on every website?

It works on regular web pages. Chrome does not let extensions run on its own pages, such as the new tab page, settings and the Chrome Web Store.

A site uses mouse dragging itself. Can I turn gestures off there?

Yes. Add the site under Exclusions on the options page, for example *.example.com/*.

Where are the options?

Click the QuickGestures icon in the Chrome toolbar, or right-click it and choose Options.
